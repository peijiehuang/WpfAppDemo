# WPF Prism 快速开发通用模板

这是一个基于 **.NET 8**、**Prism (DryIoc)**、**Material Design in XAML**、**SqlSugar** 和 **MiniExcel** 构建的高级 WPF 通用模板。它旨在为您提供一个生产就绪、颜值极高且内置 **智能代码生成器** 的企业级桌面应用起点。

---

## 🌟 核心特性

- **🚀 生产力利器：内置代码生成器**
  - **全栈生成**：一键生成 Model, IService, Service, ViewModel 以及完整的 View 层（包含 `.xaml` 和 `.xaml.cs`）。
  - **全套 CRUD 逻辑**：自动实现包含 **关键字搜索**、**分页查询**、**数据新增/编辑**、**MD 风格删除确认** 在内的完整业务闭环。
  - **一键导出与集成**：支持物理文件导出，保留目录结构，并提供傻瓜式的注册代码集成指引。
- **📊 业务功能增强**
  - **Excel 高性能导出**：集成 **MiniExcel**，支持带搜索条件的秒级数据导出，内置系统保存对话框。
  - **智能模糊搜索**：生成器自动识别表结构，选取业务字段生成 SqlSugar 模糊查询逻辑。
- **🎨 现代视觉设计**
  - **精致卡片式布局**：列表页采用统一卡片容器，标题栏与表格区域高度融合，整体感极强。
  - **全方位居中对齐**：通过精准样式控制，实现表格表头及内容数据在水平和垂直方向上的完美居中。
  - **交互体验升级**：支持无边框登录窗口自由拖拽，代码预览区支持页签水平滚动，自适应不同屏幕尺寸。
- **💬 现代化消息系统**
  - **MD 风格对话框**：基于 `DialogHost` 实现的异步弹窗，彻底告别传统 MessageBox。
- **🌍 深度国际化 (i18n)**
  - **全链路适配**：UI 界面、弹窗提示、代码生成模板均已实现中英文双语动态切换。
  - **零崩溃保护**：即使缺失资源键，系统也能优雅降级显示，确保运行稳定性。

## ⚡ 快速开发流程 (使用生成器)

1. **连接数据库**：在 `appsettings.json` 中配置您的数据库连接。
2. **启用生成器**：确保 `appsettings.json` 中的 `"EnableCodeGen": true`。
3. **选择表**：进入“代码生成器”，选定目标表，系统将立即生成全套源码预览。
4. **导出与集成**：
   - 点击“导出所有代码文件到本地”并一键打开文件夹。
   - 将文件复制到项目对应目录。
   - 按照页面 **“使用说明”**，将注册代码复制至 `App.xaml.cs` 即可。
5. **即刻运行**：重启应用，全新的业务模块（含搜索、导出、CRUD）即可投入使用。

## 🛠 技术栈

| 组件 | 说明 |
| :--- | :--- |
| **Prism.DryIoc** | MVVM 框架、依赖注入、区域管理、导航系统 |
| **MaterialDesignThemes** | 顶级的 Material Design 3 设计风格 UI 控件库 |
| **SqlSugarCore** | 极简、高性能的国产 ORM 框架 |
| **MiniExcel** | 轻量级、高性能的 Excel 处理库 |
| **Serilog** | 结构化诊断日志库 |

## 🚀 运行环境
- **IDE**: Visual Studio 2022 (v17.8+)
- **SDK**: .NET 8.0
- **数据库**: 默认为内置 SQLite (`app.db`)

---

## 📂 目录结构

- `CodeGen/`：代码生成器核心服务与 ViewModel。
- `Templates/`：代码生成器使用的各种 `.txt` 源码模板（可根据需求自定义模板风格）。
- `Services/`：包含 MessageService (MD弹窗)、ThemeService、UserService 等。
- `Models/` & `ViewModels/` & `Views/`：标准的 Prism 业务架构目录。
